# KEN AUTOS 🏎️

A clean, mobile-friendly website for **KEN AUTOS**, a premium luxury car rental business.
Featuring the Mercedes-AMG GLE 53 Coupe, with a fleet section, photo gallery, and a
built-in booking form that emails reservation requests.

## 🌐 View / host the site (GitHub Pages)

The site is a single `index.html` file — no build step needed.

To put it online so you can open it on any phone:

1. Go to **github.com/kenolad22/Git → Settings → Pages**
2. Under **Build and deployment → Source**, choose **Deploy from a branch**
3. Set **Branch** to `claude/session-brsu5f` and folder `/ (root)`, then **Save**
4. Wait ~1 minute, then refresh. GitHub shows your live link, which looks like:
   **https://kenolad22.github.io/Git/**
5. Open that link on your other phone (bookmark it / add to home screen).

## 📸 Add your car photos

See [`assets/README.md`](assets/README.md). Upload your 5–6 photos to the `assets/`
folder with the listed file names and they appear automatically.

## ✏️ Things to personalize

- **Phone number** — in `index.html`, search for "Add your phone number" and the `tel:` link.
- **Daily price** — search for `$249` and change it.
- **Location / hours** — in the "Book" section contact cards.
- **Email** — currently `kenolad22@gmail.com` (booking form + contact card).

## 🛠 Tech

Plain HTML + CSS + a little JavaScript. Fully responsive, dark luxury theme,
red AMG accent. No frameworks, no dependencies.
