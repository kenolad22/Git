# Photos for KEN AUTOS

Drop your car photos in this `assets/` folder using these exact file names.
The website automatically shows them once they're uploaded.

| File name          | Where it shows                     | Suggested photo               |
|--------------------|------------------------------------|-------------------------------|
| `gle-front.jpg`    | Big hero image + gallery           | Black GLE front (driveway)    |
| `gle-angle.jpg`    | Featured vehicle + gallery         | Black GLE front angle         |
| `gle-side.jpg`     | Gallery                            | Any other exterior shot       |
| `interior-1.jpg`   | Gallery                            | Dashboard / screens           |
| `interior-2.jpg`   | Gallery                            | Steering wheel                |
| `interior-3.jpg`   | Gallery                            | Red seats                     |

## How to upload from your phone
1. Open your repo on GitHub: **github.com/kenolad22/Git**
2. Go into the `assets` folder → tap **Add file → Upload files**
3. Select your photos, **rename them** to match the names above, and **Commit changes**.

Tip: `.jpg`, `.jpeg`, and `.png` all work — just keep the base name the same
(e.g. rename a `.png` reference in `index.html` if needed). JPG is easiest.
